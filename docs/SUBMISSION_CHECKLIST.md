# ReverieHacks submission checklist

## Completed in this repository

- [x] Working software prototype with a real routing algorithm.
- [x] Responsive browser UI with keyboard-accessible controls and visible focus states.
- [x] MIT license.
- [x] Clear local run instructions.
- [x] Architecture, privacy, and safety documentation.
- [x] Render static-site configuration.
- [x] Devpost description and demo narration.
- [x] No API keys, accounts, datasets, or build dependencies required.

## Do this before the deadline

1. Create a **public GitHub repository** named `wayfinder` and push this folder.
2. Deploy it using Render's **New + → Blueprint** flow; select the repository. Render detects `render.yaml` automatically.
3. Record the 2-minute walkthrough in [DEMO_SCRIPT.md](DEMO_SCRIPT.md). Record at 1440×900 or higher, cursor visible, with clean browser chrome. Upload it to YouTube as unlisted or to a shareable drive link.
4. In [DEVPOST_SUBMISSION.md](DEVPOST_SUBMISSION.md), replace the three placeholder links and the Team section in the README with your real links/name.
5. Submit under **Software Development** with the repository, live deployment, and video links.

## Last 60-second quality check

- Load the live link in an incognito window.
- Click Step-free, High visibility, Night, and Report a barrier; confirm the recommendation and explanation change.
- Verify the emergency disclaimer appears in the report dialog.
- Confirm the repository is public and `README.md` renders on GitHub.
- Confirm the video shows an interaction, not only slides or code.
- Do not claim the fictional campus data is real or that the prototype is emergency-navigation software.
